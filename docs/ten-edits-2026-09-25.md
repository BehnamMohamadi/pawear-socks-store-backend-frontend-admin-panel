# PAWEAR — ten approved edits

Implemented in the current backend+frontend+admin panel project. No previous product, order, payment or customer data is deleted or reset.

## Entry points
- /admin/sales: on-demand sales analytics, Tehran payment dates, Persian date entry, comparison, tables, charts and XLSX.
- /admin/articles: article management; /journal: public magazine.
- /admin/products/new and product edit: discounts, color galleries and square cropping.
- /shop?sale=1: active discounts. Listing cards link to product selection instead of adding directly.

## Accounting rules
Only verified paid payments identify a sale. One order is counted once. Current refunded orders are separate, attributed to original payment date. Merchandise sales exclude shipping. Average purchase is merchandise sales / paid orders. Box revenue is counted once; component quantities are reported separately and combined with single quantities. Product discounts do not stack onto the independent box discount. Previous periods use the same filters. Historical orders without an original-price snapshot cannot retrospectively supply a discount amount; no amount is fabricated. Customer gender defaults to unknown for existing accounts. New/returning uses earliest successful payment, not account creation.

## Product images
New uploads require 1:1, 400–6000 pixels. Admin crop outputs 1200 square, backend optimizes WebP. Each active color needs an image before saving an active product. Existing products are not silently unpublished. Old non-square photos must be cropped when reassigned. Files removed from a gallery remain on disk to preserve historical snapshots. No automatic image or database cleanup is installed.

## Journal
Four approved starter articles are added by scripts/install-journal-content.js using insert-only upserts. Existing slugs are never overwritten. Block editor escapes text; no arbitrary HTML. Cover 16:9; body images preserve proportions. Draft and publication plus mobile/desktop preview. Sources are included with each article. Generated illustrations are editorial, not photographs of specific store stock.

## Image generation

Prompt set: professional 16:9 editorial still-life photos with no text or logos, PAWEAR neutral/charcoal palette and restrained green accents. 1: clean white socks, towel and stone basin for daily care. 2: close-up charcoal, cream and oatmeal knitted socks with visible cuff and toe seam. 3: athletic, daily and formal sock/footwear flat lay. 4: cream and charcoal socks beside a mesh laundry bag and towel.

## Validation status
Only static JavaScript parsing and EJS compilation of changed files. No browser QA, checkout simulation or automated test suite was run, following the user's instruction. Runtime behavior and all viewport sizes still require the later user-authorized verification pass.
