# نگهداری دادهٔ پاور

دادهٔ اصلی در C:\Users\asus\.pawear-local\mongo نگهداری می‌شود و به جابه‌جایی پوشهٔ پروژه وابسته نیست.
در Compass این اتصال را وارد کن:

```text
mongodb://127.0.0.1:27028/pawear?replicaSet=pawearDev
```

اتصال localhost:27017 دیتابیس دیگری است. تغییر مسیر اتصال یا dbpath به پوشهٔ خالی می‌تواند ظاهری شبیه پاک‌شدن داده ایجاد کند.

## راه‌اندازی و بکاپ

```powershell
npm run dev
npm run db:backup
```

اجرای توسعه، مسیر و Replica Set را بررسی می‌کند و اگر طی ۲۴ ساعت گذشته بکاپ سالمی نباشد، پیش از شروع برنامه بکاپ می‌گیرد. این کار هنگام شروع برنامه انجام می‌شود؛ وقتی برنامه روشن نمی‌شود بکاپ زمان‌بندی‌شده‌ای گرفته نمی‌شود. بکاپ دستی همیشه یک نسخهٔ تازه می‌سازد.

بکاپ‌ها در C:\Users\asus\.pawear-backups قرار می‌گیرند. BSON، ObjectId، Date، تنظیمات collection و indexها حفظ می‌شوند. تعداد رکوردها و SHA-256 قبل از اعلام موفقیت بررسی می‌شود. نبود mongodump مانع کار نیست. نسخه‌های قبلی خودکار حذف نمی‌شوند.

اگر فایل WiredTiger وجود نداشته باشد، راه‌اندازی متوقف می‌شود؛ برنامه خودکار دیتابیس خالی جایگزین نمی‌سازد. --initialize-empty فقط برای نصب جدید است و روی داده یا نشانگر قبلی اجازهٔ اجرا ندارد.

## بازیابی بدون بازنویسی

```powershell
npm run db:restore -- "C:\Users\asus\.pawear-backups\نام-پوشه-بکاپ" pawear_restore_check
```

بازیابی فقط در نام جدید pawear_restore_* انجام می‌شود؛ نام موجود و بازنویسی pawear رد می‌شود. پس از بررسی دستی می‌توان اتصال برنامه را آگاهانه به دیتابیس بازیابی‌شده تغییر داد.

## تصاویر و محدودیت‌ها

بکاپ بالا مربوط به MongoDB است. فایل‌های آپلودی public/images را هم همراه پروژه روی محل دیگری کپی کن؛ سند محصول در MongoDB خودِ فایل تصویر را نگه نمی‌دارد. برای خرابی دیسک، یک نسخهٔ بکاپ را روی دیسک یا فضای دیگری نگه دار. این محافظت جلوی حذف دستی در Compass یا خرابی سیستم را نمی‌گیرد.

در بررسی ۱۴۰۵/۰۶/۲۱ داده‌های نسخهٔ قبلی شامل ۷ محصول، ۱ باکس، ۶ سفارش، ۶ پرداخت و ۳ کاربر پیدا و به مسیر پایدار منتقل شدند. پوشه‌های قبلی دست‌نخورده نگه داشته شده‌اند.
